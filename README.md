# Twitter Auto Poster Bot AI

Automate your Twitter/X account to post tweets regularly using the power of AI. This project leverages Google Generative AI to generate unique content around historical events/occasions for that particular day and the Twitter API to post tweets automatically.

## Features

- **AI-Generated Content**: Uses Google Generative AI to create unique tweets based on daily historical events/occasions.
- **Automated Posting**: Schedules tweets to be posted automatically at a specified time using GitHub Actions.
- **Customizable Prompts**: Easily modify the AI prompt to generate content tailored to your audience.

## Setup

### Prerequisites

- Node.js (version 20.x)
- Twitter Developer Account with API keys
- Google Generative AI API key

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/twitter-auto-poster-bot-ai.git
   cd twitter-auto-poster-bot-ai
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Create a `SECRETS.js` file with your API keys:
   ```javascript
   module.exports = {
     APP_KEY: 'your_twitter_app_key',
     APP_SECRET: 'your_twitter_app_secret',
     ACCESS_TOKEN: 'your_twitter_access_token',
     ACCESS_SECRET: 'your_twitter_access_secret',
     GEMINI_API_KEY: 'your_gemini_api_key'
   };
   ```

### Usage

- **Run Locally**: You can test the bot locally by running:
  ```bash
  npm start
  ```

- **Automated Posting**: The bot is configured to post automatically every day at 10 AM using GitHub Actions. Ensure your repository is connected to GitHub and the workflow is enabled.

### Configuration

- **GitHub Actions**: The workflow is defined in `.github/workflows/twitter.yml`. Adjust the cron schedule as needed.
- **AI Prompt**: Modify the prompt in `index.js` to customize the content generated by the AI.
